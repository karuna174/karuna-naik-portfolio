# Karuna M Naik — Portfolio

A dark, GitHub-inspired personal portfolio for a Python and full-stack software developer, built with Streamlit and custom CSS. It presents featured projects, internship experience, skills, education, a downloadable resume, and contact links in a single responsive page.

## Local Setup

1. Install Python 3.9 or newer.
2. Open a terminal in the `portfolio/` folder.
3. (Optional) Create and activate a virtual environment:
   ```
   python -m venv .venv
   source .venv/bin/activate      # Windows: .venv\Scripts\activate
   ```
4. Install the requirements:
   ```
   pip install -r requirements.txt
   ```

## How to Run

```
streamlit run app.py
```

The site opens at http://localhost:8501.
